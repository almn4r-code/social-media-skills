# مخطط المحتوى — بيت التحميص

أداة ويب لتخطيط محتوى Instagram وTikTok وSnapchat ومتابعته، تشتغل من المتصفح على ماك وويندوز والجوال.
تعطيك **كم منشور نشرتوا لكل حملة، ولكل محصول، ولكل أداة تحضير، ولكل منصة وصيغة، ولكل شخص**.

الاستضافة مجانية على Cloudflare: Pages للواجهة، وFunctions للـ API، وD1 لقاعدة البيانات، وAccess لتسجيل الدخول (مجاني لين 50 مستخدم).

## الشاشات
- **التقويم**: عرض شهري وأسبوعي مع فلاتر للمنصة والحملة والمسؤول
- **المراحل**: فكرة ← كتابة ← تصميم ← مراجعة ← مجدول ← منشور. تسحب المنشور بين المراحل أو تغيّرها من القائمة
- **التقارير**: فلتر بالفترة والمنصة، ونسبة الإنجاز، والمنشورات المتأخرة، وتنبيه للمحاصيل والأدوات اللي ما انذكرت من 30 يوم، وتصدير CSV
- **الإعدادات**: الحملات والمحاصيل والأدوات والفريق (مدير/محرر/مشاهد) وسجل التعديلات

**قاعدة العدّ:** المنشور ينحسب بس إذا حالته «منشور» وتاريخ نشره الفعلي داخل الفترة. المنشور المربوط بأكثر من محصول ينحسب مرة لكل محصول، وما يتكرر في الإجمالي.

## التشغيل على جهازك
```bash
npm install
cp .dev.vars.example .dev.vars
npm run db:local     # ينشئ الجداول ويضيف بيانات تجريبية
npm run dev          # http://localhost:8788
npm test
```

## النشر (مرة وحدة، تقريبًا 15 دقيقة)
1. سوّ حساب Cloudflare مجاني، وبعدين شغّل `npx wrangler login`.
2. أنشئ قاعدة البيانات بالأمر `npx wrangler d1 create roastery-planner`، وانسخ `database_id` اللي يطلع لك في `wrangler.toml`.
3. أنشئ الجداول بالأمر `npx wrangler d1 migrations apply roastery-planner --remote`. لا تشغّل `seed.sql` على قاعدة الإنتاج.
4. في Cloudflare افتح Workers & Pages ← Create ← Pages ← Connect to Git، واختر هذا الريبو. حط Root directory على `apps/roastery-planner`، وخلّ Build command فاضي، وحط Output على `public`. بعدها كل push ينشر تلقائيًا.
5. فعّل Cloudflare Access: من Zero Trust ← Access ← Applications ← Self-hosted، وحط رابط `*.pages.dev` حقك، وأضف سياسة Allow بإيميلات الفريق. ممكن يطلب بطاقة، بس المبلغ يبقى صفر لين 50 مستخدم.
6. من نفس التطبيق انسخ قيمة **AUD**، واسم فريقك (مثل `your-team.cloudflareaccess.com`). وبعدين أضف هالمتغيرات في إعدادات مشروع Pages أو في `wrangler.toml`:
   - `ACCESS_TEAM_DOMAIN`
   - `ACCESS_AUD`
   - `ADMIN_EMAILS` وفيه إيميلك، عشان تدخل كمدير أول مرة
7. افتح الرابط، وأضف الفريق والحملات والمحاصيل والأدوات من **الإعدادات**.

> الأمان: الـ API يتحقق من توقيع Cloudflare Access على كل طلب. وإذا ما ضبطت `ACCESS_AUD` و`ACCESS_TEAM_DOMAIN` يرفض كل الطلبات.
